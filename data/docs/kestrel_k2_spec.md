# Kestrel K2 Inspection Drone: Technical Specification

The Kestrel K2 is Veridian Dynamics' second-generation industrial inspection drone, launched in March 2025. It replaced the Kestrel K1, which was discontinued in December 2024.

## Flight performance

- Maximum flight time: 52 minutes with no payload, 38 minutes with the full thermal payload.
- Maximum speed: 72 km/h.
- Maximum wind resistance: 12 m/s.
- Operating temperature: -20 °C to 50 °C.
- Weight: 2.4 kg including the battery.
- Ingress protection rating: IP55.

## Sensors

The K2 carries a 48-megapixel visual camera and a 640x512 radiometric thermal camera. An optional LiDAR module (the K2-L add-on) maps structures with 2 cm accuracy at up to 80 metres range.
Obstacle avoidance uses six stereo vision pairs giving 360-degree coverage. Obstacle avoidance is disabled automatically when flying below 1 lux of ambient light.

## Battery and charging

The K2 uses the VB-90 smart battery (90 Wh). A full charge takes 55 minutes with the standard charger or 30 minutes with the RapidDock charging station. Batteries are rated for 400 charge cycles before capacity drops below 80%.

## Software

Flight planning uses the Veridian Mission Studio desktop app. Firmware updates are released quarterly. The K2 supports automated "digital twin" inspection routes that repeat the exact same flight path for change detection between inspections.

## Pricing

The base Kestrel K2 costs 7,900 USD. The K2-L LiDAR add-on costs 3,200 USD. The RapidDock costs 1,450 USD.
